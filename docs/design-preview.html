ملاحظات التصميم: الهوية مبنية على ألوان دافئة مصرية (طوبي + ذهبي فرعوني + كريمي) مع خط Cairo للعناوين وTajawal للنصوص، والاتجاه RTL بالكامل. زخرفة «الزيجزاج» الفرعونية تظهر كشريط فاصل رفيع فقط (في الهيرو وأسفل الصفحات) لطلة مصرية بدون مبالغة. جانب الأستاذ يوظّف الطوبي/البني الداكن، بينما جانب الطالب يستخدم النيلي كرمز للنجاح والتقدم — مع الحفاظ على نفس العائلة البصرية. الشريط الجانبي انتقل لليمين (RTL) والأسهم والاتجاهات كلها معكوسة تلقائياً مع خصائص logical properties. هذه معاينة ثابتة (Mockup) — التنفيذ هيتم في تطبيق React الحالي بنفس الألوان والخطوط عبر Tailwind.
